# Changelog

## v1.0.2

- Fixed players being unable to join because of fake addresses from the internet.
- Connection details no longer list strangers as players trying to join.
- A router behind another router is no longer reported as having an open port.

## v1.0.1

- Joining a lobby over the internet connects faster and more reliably.
- GameLAN removes Windows Firewall rules that block it, such as those left by a dismissed firewall prompt.
- Connection details show more of what happens while joining.

## v1.0.0

- First release.
- Host or join a lobby with an 8-character code. No accounts, no port forwarding.
- Players connect directly to the host over an encrypted link.
- LAN games show up in each other's LAN browsers, including older games.
- Lobbies hold 2 to 32 players.
- Pass the host role to another player so the lobby stays open after you leave.
- See every player's ping, and hover over an IP address to copy it.
- Optionally let lobby players through Windows Firewall, asked once.
- Closing the window keeps you in the lobby; GameLAN stays in the system tray.
- Copy connection details, or open them in a separate window.
- About window with links to releases and support.
